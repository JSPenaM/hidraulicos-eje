# Hidráulicos del Eje – Landing Page

Landing page profesional optimizada para Google Ads. Servicio técnico de reparación de herramientas hidráulicas en Pereira y Dosquebradas.

## Tecnologías

- **Vue 3** (Composition API)
- **Vite**
- **Vuetify 3**
- Diseño responsive (mobile-first)
- Sin backend

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173) en el navegador.

## Build para producción

```bash
npm run build
```

Los archivos quedan en la carpeta `dist/`.

## Preview del build

```bash
npm run preview
```

## Estructura del proyecto

- `src/components/` – Secciones de la landing (Hero, Problemas, Servicios, Beneficios, Cobertura, CTA, WhatsApp flotante)
- `src/config/contact.js` – Teléfono y enlace de WhatsApp (fácil de actualizar)
- `src/plugins/vuetify.js` – Tema industrial (azul, amarillo, rojo)
- `index.html` – Meta tags SEO y Open Graph
